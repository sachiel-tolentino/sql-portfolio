# SQL Portfolio — Sachiel Trisha Tolentino

A collection of SQL queries written in Google BigQuery 
as part of the Google Data Analytics Professional Certificate on Coursera.

## About
These queries demonstrate my ability to extract, filter, 
aggregate, join, and clean data using SQL in Google BigQuery.
They progress from basic filtering to advanced CTEs and subqueries.

## Queries Included
1. Basic SELECT with WHERE Filter
2. ORDER BY ASC with Multiple Filters
3. ORDER BY DESC with OR Conditions
4. CONCAT for String Combination
5. COALESCE for NULL Handling
6. CAST and FLOAT64 Data Type Conversion
7. INNER JOIN
8. LEFT JOIN with AVG and GROUP BY
9. Aggregate Data with Subqueries + CASE WHEN
10. WITH Query — CTE with Hashtag Comments

## Tools Used
- SQL
- Google BigQuery
- Google Data Analytics Certificate — Coursera (In Progress)
